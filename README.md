# Login


Frontend

React 19 with TypeScript
Vite for development and production builds
React Router for page routing
Separate client and admin applications
Bootstrap / React-Bootstrap and custom CSS/SCSS for styling
English and Hindi language selection in the client and admin portals, saved in the browser
Backend

Node.js with TypeScript
Express 5 for the REST API
SQLite, accessed through better-sqlite3, for the database
JWT and secure cookies for sessions; bcryptjs for password hashing
Helmet and express-rate-limit for security protections
Nodemailer for optional email delivery
See the client package manifest, admin package manifest, and backend package manifest.
